# CineMind 🎬

AI-powered movie recommendation platform that delivers personalized movie suggestions using user preferences, mood analysis, and AI-generated explanations.

## Features

- 🎯 Personalized recommendations
- 🤖 AI-generated recommendation explanations
- 😊 Mood-based movie discovery
- ❤️ Favorites management
- 📊 User dashboard
- 🔍 Movie search powered by TMDB

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### Database
- SQLite

### APIs
- TMDB API
- DeepSeek API
