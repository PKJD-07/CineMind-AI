# CineMind 🎬

AI-powered movie recommendation platform that delivers personalized movie suggestions using user preferences, mood analysis, and AI-generated explanations.

## Features

🔐 JWT Authentication

🎬 TMDB Movie Search

❤️ Favorites Management

🤖 AI-Powered Personalized Recommendations

🧠 AI Match Score

📊 Dashboard Analytics

🌙 Modern Responsive UI

⚡ FastAPI Backend

🔍 Advanced Filtering

## Tech Stack

| Frontend | Backend | Database | AI   | API  |
| -------- | ------- | -------- | ---- | ---- |
| React    | FastAPI | SQLite   | Groq | TMDB |

## Installation

git clone

cd CineMind-AI

pip install -r requirements.txt

npm install

python run.py

npm run dev
